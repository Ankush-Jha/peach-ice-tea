Saves one short note to your scratchpad, which is kept outside the conversation. When earlier messages are summarised to save space, the notes you wrote are shown to you again word for word, so a note survives what a summary would paraphrase or drop.

Write a note for a fact you will need later and cannot cheaply look up again: the root cause you found, the exact test command that works, a decision and its reason, or the file and function you still have to change. Do not note what a file already says, and do not use notes as a todo list (use `todo_write` for that).

Each call saves one note of at most 500 characters. The 20 most recent notes are kept.
